# Contributing

Thanks for your interest in MyAniCommu!

1. Fork the repo and create a branch from `develop`.
2. Follow the setup in the [README](README.md#getting-started).
3. Run `bun run lint` and `bunx tsc --noEmit` before pushing.
4. Open a pull request against `develop` and describe what changed and why.

Never commit secrets: `.env*` files are git-ignored, use `.env.example` for new variables.
